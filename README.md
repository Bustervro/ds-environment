# ds-environment

# Data Science Environment Setup

## Project Description
This project demonstrates how to create and manage a Python data science environment using uv.

## Tools Used
- Python
- uv
- Pandas
- Matplotlib
- Jupyter
- GitHub Codespaces

## Project Setup
1. Create a Python project with uv.
2. Install Pandas, Matplotlib, and Jupyter.
3. Generate a uv.lock file.
4. Run uv tree to check installed dependencies.
5. Answer five questions about Python environments.

## Commands Used

uv init ds-environment

cd ds-environment

uv add pandas matplotlib jupyter

uv tree

## What I Learned
I learned how to create an isolated Python environment, manage packages, and use lockfiles to keep projects organized and reproducible.
